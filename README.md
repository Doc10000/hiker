> Туризм растёт быстрее сервиса. На Кольсае нет стабильной мобильной связи —
> турист уходит в горы и становится невидимым для близких.
> Мы даём: маршрут, что взять (под уровень), метку для родных и SOS.

## Почему это стоит взять (для жюри)

**Проблема.** Туризм в Казахстане растёт быстрее сервиса: на горных маршрутах
связь пропадает, а приложение для «пойти в горы» — это либо такси/отели, либо
заграница. Турист уходит в горы и перестаёт существовать для родных: они не
знают, вернётся он вовремя или нет.

**Решение — один офлайн-компаньон.** Не «ещё один каталог туров», а инструмент,
который работает там, где связь кончилась: **всё считается на телефоне, без
сервера и регистрации**, а интернет нужен только для живой метки и прогноза.

**Что реально работает, а не нарисовано (проверялось в APK):**

| | |
|---|---|
| 🗺 **Реальные тропы** | 6 маршрутов по данным OpenStreetMap, геометрия до **500 точек** — линия повторяет тропу, а не нарисована от руки; соседние тропы и инфраструктура на карте |
| 📴 **Офлайн-режим** | карта, чек-лист, SOS, трек и метка работают **в самолётном режиме**; метка для родных — данные зашиты в ссылку, сервер не нужен |
| ⏱ **Таймер возврата** | не вернулся в срок → **авто-SMS близким** с координатами, повтор до 3 раз, живая метка с пометкой «не отметился» |
| 🌦 **Погода как фактор риска** | прогноз по точке старта → вердикт **«можно идти / с осторожностью / сегодня не стоит»** и **+до 40 к оценке риска**; при опасной погоде кнопка не пускает без явного «Всё равно идти» |
| ✅ **Риск 0–100** | 15+ факторов: сложность против уровня, высота, связь, снаряжение, погода; при высоком риске приложение предлагает **маршруты полегче** |
| 🎒 **Чек-лист под уровень** | новичок получает больше «взять», профи — меньше; блокирует старт только **критичное** (8 из 16 пунктов) |
| 🌍 **8 языков** | ru/en/kk/zh/hi/ar/ko/tr с флагами, выбор на **самом первом экране**, арабский — RTL; **3561 перевод** |
| 🆘 **SOS** | координаты без сети, звонок, SMS, копирование; единый формат инцидента для канала «112»/МЧС |

**Масштаб.** Один APK на любой Android, нулевая стоимость инфраструктуры в
базовом сценарии (всё локально), открытые данные OSM. Модульный: те же правила
риска, чек-листа и метки переносятся на другой регион или страну добавлением
маршрута, переводы — пакетным скриптом.

**Инструменты (п. 6.3):** Leaflet 1.9.4 · OpenStreetMap (ODbL) · Capacitor 7 ·
Open-Meteo (CC BY4.0) · геолокация GPS · AI-ассистент **OpenCode**; шаблоны и
no-code не использовались.

## Что внутри

| Функция | Как работает |
|---|---|
| **Онбординг** | Имя, опыт, уровень, своё снаряжение, контакт близкого → все рекомендации подстраиваются |
| **6 маршрутов** | БАО, Тургень, Чарын, Кольсае ×2, Кок-Жайляу. Треки лежат локально, фильтр по уровню |
| **Карта офлайн** | Canvas-рендер трека, GPS-прогресс — без тайлов и без интернета |
| **Чек-лист под уровень** | Генерируется локальными правилами из профиля: новичок получает больше «взять», профи — меньше |
| **Таймер возврата** | «Вернусь до 18:00» → просрочка = автоинцидент + SMS близкому |
| **Ссылка-метка** | Данные похода кодируются в саму ссылку → близкий видит карту **без сервера** |
| **Погода** | Open-Meteo по точке старта → вердикт «идти / не идти» и **+к оценке риска** (гроза, порывы, мороз) |
| **SOS** | Координаты (GPS без сети), SMS, звонок, копирование сообщения |
| **IncidentService** | Единый интерфейс событий. Канал «родственник» — работает, канал «МЧС» — задел (один шлюз) |

## Стек

- **Capacitor 7** → APK (весь код внутри; единственный внешний запрос — прогноз погоды Open-Meteo, кэшируется на 20 мин)
- Обычные HTML/CSS/JS, canvas-карта, localStorage, Geolocation API
- Разрешения: `ACCESS_FINE_LOCATION` (прогресс и SOS)

## Страница близкого

> ⚠️ **Демо, бета-версия.** Страница близкого сейчас в бете: живое обновление
> позиции работает только пока поднят сервер метки, без него страница показывает
> последние данные, зашитые в саму ссылку. Постоянный хостинг и продакшн-режим —
> в перспективах ниже.

`www/share.html` — открывается по ссылке-метке, читает данные из URL-хэша,
рисует последнюю точку и статус срока.

## Демо-сценарий (3 минуты)

1. Онбординг: «новичок, ничего нет» → чек-лист максимум, маршруты ≤ уровня
2. Самолётный режим → всё работает (карта, чек-лист, SOS)
3. Начать поход (Кольсае) → метка близким → второй телефон открывает ссылку
4. Не вернулся по таймеру → авто-SMS
5. SOS → инцидент в очереди → раздел «Службы спасения»: формат события МЧС

## Живая метка для близких (сервер + туннель)

Сервер пишет позицию похода, страница близкого опрашивает его каждые 15 секунд
и показывает **«обновлено N сек назад»** и статус: всё норм / дошёл / не отметился / тревога.

```powershell
# поднять сервер + публичный туннель (адрес напечатается сам)
powershell -ExecutionPolicy Bypass -File server\start.ps1
```

1. Скопировать напечатанный `https://....trycloudflare.com`
2. В приложении: **Ещё → Мои близкие → Адрес сервера метки → Сохранить сервер**
3. Отправить метку близкому — адрес сервера уже зашит в ссылку

| Где приложение | Адрес сервера |
|---|---|
| Эмулятор Android | `http://10.0.2.2:8087` |
| Телефон и ПК в одной Wi-Fi | `http://<IP ПК>:8087` |
| Из любой сети (рекомендуется) | `https://....trycloudflare.com` из `start.ps1` |

Без сервера метка работает как раньше — данные зашиты в саму ссылку.

## Перспективы

- **Поднять сервер + публичный туннель** (адрес напечатается сам) — сейчас сервер
  метки поднимается вручную на ноутбуке (`server\start.ps1`); нужен постоянный,
  чтобы страница близкого жила, когда ноутбук выключен.
- **Страница близкого из беты в прод:** свой домен, шифрование ссылки, пуш-уведомление близкому.
- **Погода:** почасовой прогноз на весь поход и push-уведомление при ухудшении.
- **Канал «МЧС»:** подключить шлюз — единый формат события уже готов.
- **Маршруты и языки:** больше маршрутов по Казахстану и перевод динамических строк.
