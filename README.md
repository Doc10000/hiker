# Горный хайкер 🏔

Офлайн-компаньон для горных походов по Казахстану. **Кейс 2 — Путешествие по Казахстану.**

> 🏆 **Хакатон hackathon.kz** — пакет для сдачи в [`hackathon/`](hackathon/):
> `IDEA.md` (идея под критерии) · `PITCH_10_SLIDES.md` · `PITCH_VIDEO_3MIN.md` ·
> `RECOMMENDATIONS.md` (рекомендации по уровню) · `SUBMISSION.md` (заявка).

> Туризм растёт быстрее сервиса. На Кольсае нет стабильной мобильной связи —
> турист уходит в горы и становится невидимым для близких.
> Мы даём: маршрут, что взять (под уровень), метку для родных и SOS.

## Что внутри

| Функция | Как работает |
|---|---|
| **Онбординг** | Имя, опыт, уровень, своё снаряжение, контакт близкого → все рекомендации подстраиваются |
| **6 маршрутов** | БАО, Тургень, Чарын, Кольсае ×2, Кок-Жайляу. Треки лежат локально, фильтр по уровню |
| **Карта офлайн** | Canvas-рендер трека, GPS-прогресс — без тайлов и без интернета |
| **Чек-лист под уровень** | Генерируется локальными правилами из профиля: новичок получает больше «взять», профи — меньше |
| **Таймер возврата** | «Вернусь до 18:00» → просрочка = автоинцидент + SMS близкому |
| **Ссылка-метка** | Данные похода кодируются в саму ссылку → близкий видит карту **без сервера** |
| **SOS** | Координаты (GPS без сети), SMS, звонок, копирование сообщения |
| **IncidentService** | Единый интерфейс событий. Канал «родственник» — работает, канал «МЧС» — задел (один шлюз) |

## Стек

- **Capacitor 7** → APK (весь код внутри, внешних запросов нет)
- Обычные HTML/CSS/JS, canvas-карта, localStorage, Geolocation API
- Разрешения: `ACCESS_FINE_LOCATION` (прогресс и SOS)

## Сборка APK

```powershell
# разово: JDK 21 + Android SDK (уже установлены: F:\tools\jdk21)
$env:JAVA_HOME = "F:\tools\jdk21"

# синхронизация web → android и сборка
cd F:\proects\hiker
npx cap sync android
cd android
.\gradlew.bat assembleDebug
```

APK: `android\app\build\outputs\apk\debug\app-debug.apk`

## Эмулятор

```powershell
$sdk = "$env:LOCALAPPDATA\Android\Sdk"
& "$sdk\emulator\emulator.exe" -list-avds
& "$sdk\platform-tools\adb.exe" install -r android\app\build\outputs\apk\debug\app-debug.apk
```

GPS в эмуляторе: Extended Controls → Location → задать координаты
(старт Кольсае: `43.218, 78.290`) или Points to route.

## Страница близкого

`www/share.html` — открывается по ссылке-метке, читает данные из URL-хэша,
рисует последнюю точку и статус срока. Для продакшена хостится как статика.

## Демо-сценарий (3 минуты)

1. Онбординг: «новичок, ничего нет» → чек-лист максимум, маршруты ≤ уровня
2. Самолётный режим → всё работает (карта, чек-лист, SOS)
3. Начать поход (Кольсае) → метка близким → второй телефон открывает ссылку
4. Не вернулся по таймеру → авто-SMS
5. SOS → инцидент в очереди → раздел «Службы спасения»: формат события МЧС
6. Физика: свисток и QR-бейдж с планом похода (3D-печать)
