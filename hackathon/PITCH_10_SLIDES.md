## Слайд2 · Проблема: сервис отстаёт от роста
- Внутренний туризм **7,1 →8,7 млн** (2023 →2025)
- **15,7 млн** визитов, из Китая **+46,8%**
- Цель: **11 млн** внутренних туристов к2029
- В нацпарках **нет туалетов, копится мусор**
- **На Кольсае нет связи** — турист становится невидимым

---

## Слайд3 · Кто страдает
- **Турист без опыта** — не знает, что взять
- **Турист в горах** — нет связи и помощи
- **Близкие** — не знают, вернётся ли он
- **Гиды** — не видят группу, отвечают вслепую

---

## Слайд4 · Решение
1. **Реальные тропы** (OSM) + соседние тропы + инфраструктура
2. **Офлайн:** карта без интернета, GPS без сети
3. **Уровень считается по пройденным походам**
4. **Риск0–100** → при высоком риске — маршрут полегче
5. **Короткий чек-лист**, блокируется только критичное
6. **Запланированные походы** с обратным отсчётом
7. **«Кого уведомить?» → SMS уходит сама**
8. **Живая метка:** «обновлено N сек назад», статус
9. **Таймер → автотревога** при неявке, без нажатий
10. **SOS + IncidentService** — формат для служб

---

## Слайд5 · Живой сценарий
- Онбординг → **единое окно рекомендаций + одна галка**
- Карта: **реальная тропа**, инфраструктура, «нет связи»
- **Риск90/100** → предложены маршруты полегче
- **Обязательный чек-лист** → дальше только после отметки
- **SMS уходит сама** → метка на втором телефоне
- **Самолётный режим** → всё работает

---

## Слайд6 · Боль кейса: инфраструктура
- На карте: **туалеты, вода, укрытия, мусор, смотровые**
- Турист видит, что есть — меньше стресса и мусора
- Парки видят, **чего не хватает**
- Прямая цитата кейса про туалеты и мусор

---

## Слайд7 · Выгодно принимающим
- **Гиды/операторы:** видят группу, меньше рисков
- **Парки:** данные инфраструктуры для планирования
- **Службы:** один шлюз `IncidentService` вместо звонков
- **Модель:** бесплатно туристам · подписка операторам · данные паркам

---

## Слайд8 · Техническая реализация
- PWA (HTML/CSS/JS) → **Capacitor7** → Android APK
- **Leaflet + OpenStreetMap** (тропы © OSM, ODbL) + **canvas-фолбэк** офлайн
- GPS `watchPosition` **без интернета**; метка — случайный `tripId`
- `localStorage` + **локальный сервер метки** (Python) с публичным туннелем
- `IncidentService`: единый формат, канал «112» = один POST
- Авто-SMS: нативный плагин `SmsManager` + `ContactsContract`
