# Питч-видео «Горный хайкер» — сценарий до 3 минут

> Требование 6.1: питч-видео **до3 минут**. Итоговый хронометраж — **2:50**.
> Формат: лицо ведущего + запись экрана (портрет,1080p) + короткие титры.
> Темп ~150 слов/мин, паузы не дольше1 сек. Тайминг ниже — держать секунды.

## Что обязательно показать на экране (снимать, не пересказывать)

1. **Онбординг** —4 шага быстрым тапом.
2. **Единое окно рекомендаций** + постановка **одной галки**.
3. **Карта:** реальная тропа, соседние тропы пунктиром, точки инфраструктуры, **сдвиг карты пальцем**.
4. **Оценка риска** — шкала0–100 и тап по альтернативному маршруту (риск падает).
5. **Обязательный чек-лист** — неактивная кнопка → активная.
6. **Тост «Отправлено:2»** — SMS ушла без единого лишнего тапа.
7. **Второй телефон:** живая метка, «обновлено N сек назад», статус «всё норм».
8. **Самолётный режим** — включить прямо в кадре.
9. *(если хватит времени)* **SOS** и JSON события `IncidentService`.

## Советы по съёмке

- Снимать **портрет**, экран телефона крупно, палец не закрывает кнопки.
- Держать в кадре лицо + экран (картинка-в-картинке) — так читается лучше.
- Ничего не читать со слайда — говорить своим словами, слайды только подтверждают.
- Голос громко, без «эээ», без пауз дольше1 сек.
- Общая длина: **не больше2:50** (лимит3:00) — при монтаже держать запас10 секунд.
