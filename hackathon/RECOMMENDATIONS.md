# Рекомендации по уровню профессионализма

Персонализация — ядро продукта. Приложение определяет уровень в онбординге и под **каждый** элемент выдаёт рекомендацию: маршрут, чек-лист, советы.

## 1. Как определяется уровень

Онбординг (4 вопроса):
1. Имя.
2. Сколько походов за последний год: `0` / `1–3` / `4–10` / `10+`.
3. Уровень: **1 — Новичок** (горы впервые), **2 — Опытный** (хожу регулярно), **3 — Профи/гид**.
4. Что уже есть: палатка, спальник, палки, аптечка, пауэрбанк, навигатор / «почти ничего».
5. Контакт близкого (имя + телефон).

Итоговый уровень в `profile.level` (1–3), снаряжение — в `profile.gear`.

## 2. Маршруты по уровню

| Уровень | Рекомендуемые маршруты | Логика |
|---|---|---|
| **1 — Новичок** | БАО (1 дн., 8 км), Чарын (1 дн., 12 км) | Короткие, без ночёвок, `difficulty ≤ 1–2` |
| **2 — Опытный** | + Тургень—Кайынды (2 дн.), Кольсае—Верхнее (2 дн., нет связи) | Ночёвки, высота до 2700 м |
| **3 — Профи** | + Кольсае—Кайынды (3 дн., перевал 3000 м), Кок-Жайляу (2 дн., 3400 м) | Многодневки, высокогорье, `difficulty 4–5` |

Правило: на главной экране блок «Рекомендовано по вашему профилю» показывает маршруты с `difficulty ≤ level`, остальное — в «Все маршруты». Маршруты выше уровня визуально отделены.

## 3. Чек-лист: приоритеты под уровень

Каждый пункт получает приоритет:

| Приоритет | Значение | Пример |
|---|---|---|
| **`must` (взять)** | Обязательно, иначе риск | Мембранная куртка, аптечка, вода |
| **`should` (желательно)** | Сильно рекомендуется | Термобельё, перчатки |
| **`have` (есть)** | Уже есть в снаряжении → не покупать | Палатка, если отмечена в профиле |

**Правила генерации (движок `buildChecklist` в `data.js`):**

- **Снаряжение:** если пункт уже отмечен в профиле → `have` (не тратить деньги).
- **Новичок (1):** добавляется блок «Советы новичку» (идти группой, разворот — нормально, прогноз погоды, оставить маршрут близким); усиленные требования (аптечка новичка, вода).
- **Опытный (2):** базовый набор, без избыточных подсказок.
- **Профи (3):** убирается лишнее, остаётся критичное; для сложных маршрутов добавляются жгут/аспирин, голенищи.
- **Маршрут:** `noSignal` → пауэрбанк 10 000 мАч и сигнал-свисток; высота > 2500 м → термос; `difficulty ≥ 4` → голенищи, жгут; ночёвка (`days ≥ 2`) → палатка/спальник/горелка.
- **Сезон/тип:** зимний/летний набор учитывается через `season` и `alt`.

## 4. Рекомендации в интерфейсе

- На главной: «Рекомендовано по вашему профилю» + чип уровня (`Опытный · 4–10 походов/год`).
- На маршруте: блок «Инфраструктура маршрута» — что реально есть на треке (туалеты, вода, укрытия, мусор).
- Чек-лист: заголовок «Составлено под ваш профиль: *уровень*, маршрут, высота, сезон».
- Советы новичку — отдельной категорией в чек-листе.
