## 1. Описание (для формы)

**Название:** Горный хайкер

**Описание:**

> Офлайн-компаньон походов по Казахстану. Туризм растёт быстрее сервиса: внутренних туристов8,7 млн, иностранцев15,7 млн, а на Кольсае нет связи — турист уходит в горы и становится невидимым. Приложение показывает **реальные тропы из OpenStreetMap** с инфраструктурой (туалеты, вода, укрытия, мусор), считает **уровень по пройденным походам**, оценивает **риск0–100** и при высоком риске предлагает маршрут полегче, ведёт через **короткий обязательный чек-лист**, планирует походы с обратным отсчётом и **автоматически отправляет SMS** выбранным контакты при старте, в SOS и при неявке в срок. Близкие видят **живую метку**: «обновлено N сек назад» и статус «всё норм / не отметился». Работает полностью офлайн, на пяти языках. Бесплатно туристам, подписка туроператорам, данные инфраструктуры для парков.

**Прототип:** https://doc10000.github.io/hiker/www/index.html (PWA, работает офлайн) · APK прилагается

## 3. ⚠️ П.6.2 «Готовые ранее проекты не принимаются»

Проект должен **создаваться во время Хакатона**:

1. Коммиты идут в период события — историю видно в репозитории.
2. Каждая фича под кейс — отдельный коммит (тропы OSM, оценка риска, живая метка, автотревога, языки).
3. Если проект существовал раньше — оформляем как **новую работу по кейсу**: описание, прототип и демо сделаны здесь.
4. Даты коммитов сохраняем — жюри может проверить.

## 5. Демо-чек-лист перед сдачей

- [ ] PWA открывается, онбординг проходится, **единое окно рекомендаций закрывается одной галкой**.
- [ ] Карта маршрута: **реальная тропа OSM**, соседние тропы, инфраструктура, зум и перетаскивание пальцем.
- [ ] **Оценка риска** показывает факторы и предлагает альтернативный маршрут.
- [ ] **Чек-лист** короткий, старт блокируется только из-за критичных пунктов.
- [ ] **SMS уходит автоматически** (тост «Отправлено: N»).
- [ ] **Живая метка** открывается на втором телефоне: «обновлено N сек назад» + статус.
- [ ] **Самолётный режим** — приложение продолжает работать.
- [ ] **Не отметился в срок** → авто-SMS без ручных нажатий.
- [ ] Языки переключаются флагами: 🇷🇺 🇬🇧 🇰🇿 🇨🇳 🇮🇳.
- [ ] Кнопка «назад» Android возвращает по стеку, с главной — выход.
- [ ] Презентация **≤10 слайдов**, видео **≤3 мин**, слайд9 с инструментами заполнен.
- [ ] Атрибуция OpenStreetMap (ODbL) видна на экране маршрута.
